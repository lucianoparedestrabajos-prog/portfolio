## 🚀 Cómo Usar en GitHub Pages

### Opción 1: Crear Repositorio Nuevo

1. Ve a [github.com/new](https://github.com/new)
2. **Nombre del repositorio:** `portfolio` (o `tu-nombre-portfolio`)
3. Selecciona **Public**
4. Click en **Create repository**

### Opción 2: Subir Archivos

1. Haz click en **Add file** → **Upload files**
2. Arrastra TODOS los archivos de esta carpeta
3. Escribe el mensaje: "Initial commit - Portfolio profesional"
4. Click en **Commit changes**

### Opción 3: Activar GitHub Pages

1. Ve a **Settings** en tu repositorio
2. En el menú izquierdo, busca **Pages**
3. En **Source**, selecciona **main** (rama)
4. Click en **Save**

### 🎉 ¡Listo!

Tu portafolio estará disponible en:
```
https://tu-usuario.github.io/portfolio
```

Por ejemplo, si tu usuario es `luciano`, sería:
```
https://luciano.github.io/portfolio
```
